## Build a Simple API Client using Python
## Project Description
This project demonstrates how to build a simple API client using Python. It connects to a public REST API, retrieves JSON data, and displays selected information in a clean and readable format.## 
## Objective
To understand basic API consumption, HTTP requests, and JSON response handling using Python.
## Technologies Used
- Python
- Requests Library
- JSON
- JSONPlaceholder Public REST API
## Features
- Sends GET requests to a public REST API.
- Retrieves data in JSON format.
- Displays Post ID, User ID, Title, and Body.
- Checks HTTP status codes.
- Handles connection failures and timeouts.
- Handles invalid JSON responses.
## API Used
https://jsonplaceholder.typicode.com/posts/1
Installation
Install the required Python library:
pip install requests
## How to Run
1. Download or clone the project.
2. Install the requests library.
3. Open the project in a Python editor.
4. Run "api_client.py".
5. View the API response in the output terminal.
